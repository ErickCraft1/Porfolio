# Erick Moya - Portfolio

## About

Personal portfolio showcasing my experience, projects, skills, and web

## Sobre el proyecto

Portafolio personal que presenta mi experiencia, proyectos, habilidades y
trabajo de desarrollo web.

## Technical Highlights

- Built with Astro SSR and Tailwind CSS.
- Deployed on Cloudflare Workers.
- Integrated GitHub's Contents API through Octokit Core.
- Loads Java exercises dynamically from the
  [Practica_Java](https://github.com/ErickCraft1/Practica_Java) repository.
- Includes collapsible exercise navigation and client-side search.
- Keeps GitHub credentials server-side through Cloudflare environment secrets.

## Aspectos técnicos destacados

- Construido con Astro SSR y Tailwind CSS.
- Desplegado en Cloudflare Workers.
- Integración con la API Contents de GitHub mediante Octokit Core.
- Carga dinámicamente ejercicios de Java desde el repositorio
  [Practica_Java](https://github.com/ErickCraft1/Practica_Java).
- Incluye navegación de ejercicios desplegable y búsqueda del lado del cliente.
- Mantiene las credenciales de GitHub en el servidor mediante secretos de
  entorno de Cloudflare.
